AGENTES QUE VENDEM — DEMO PUBLICA VERCEL

Esta pasta contem SOMENTE a apresentacao comercial estatica.
Nao contem /admin, /setup, banco, chaves, Meta ou PurinCash.

Deploy mais simples:
1. Acesse https://vercel.com/new (ou Vercel Drop).
2. Escolha upload/drag-and-drop.
3. Envie este ZIP ou esta pasta.
4. Nome sugerido: agentes-que-vendem-demo
5. Clique Deploy.
6. Abra a URL *.vercel.app gerada e teste no celular antes de enviar para uma loja.

A demo e roteirizada. Os dados e pagamentos exibidos sao demonstrativos.
